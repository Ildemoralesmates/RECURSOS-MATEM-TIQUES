# Recursos de matemàtiques

Activitats interactives per a l'alumnat de matemàtiques, física i curiositats. Cada recurs és una pàgina independent que funciona al navegador, sense instal·lar res.

**Portada:** https://ildemoralesmates.github.io/

## Recursos

**Matemàtiques**
- `fites-matematiques/` — Vint fites de la història de les matemàtiques amb un problema detonant per a cada una.
- `eratostenes/` — Criba d'Eratòstenes (1–500).
- `laboratori-mates/` — Cinc simulacions per a 2n ESO (Pitàgores, balança, fraccions, Thales, proporció).
- Matrius: `matrius-activitats/`, `graus-separacio/`, `matriu-rotacio/`, `autovectors/`, `detector-vores/`, `convolucio-12x12/`, `filtre-matrius/`, `cifra-hill/`.

**Física**
- `tir-parabolic/` — Simulador de tir parabòlic.
- `escala-univers/` — Escala de l'univers (potències i notació científica).

**Miscel·lània**
- `maquina-temps/` — Aventura interactiva.

**Curiositats**
- `atles-art-rupestre/` — Atles de l'art rupestre del món.

## Com afegir un recurs
Crea una carpeta amb un `index.html` autosuficient i afegeix-lo a la llista `RES` de `index.html` i al `sitemap.xml`.
